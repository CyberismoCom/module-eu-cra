== Introduction
Configuration management covers how different configuration items are managed. This card describes the configuration management plan for a single configuration item type.

== Configuration item type and scope

This card covers the configuration management for requirements, including security requirements.

All product requirements, including but not limited to security requirements, must be documented and there must be a process to review and approve changes to the requirements.
