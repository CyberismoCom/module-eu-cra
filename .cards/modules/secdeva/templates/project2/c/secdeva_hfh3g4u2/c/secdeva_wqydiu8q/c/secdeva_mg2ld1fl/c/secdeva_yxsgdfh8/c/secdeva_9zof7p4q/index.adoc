Security requirement testing ensures that security requirements have been correctly implemented.

When security requirements mitigate cyber risks, security requirement testing acts as mitigation testing. In this case, the testing should include, where practical, tests that attempt to defeat (thwart) the mitigation.

== How to decide if this control is required

This control is required, if security requirements have been identified.
