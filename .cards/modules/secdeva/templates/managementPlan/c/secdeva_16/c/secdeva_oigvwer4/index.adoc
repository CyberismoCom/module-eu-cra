== Task description

Review the configuration management plan.

[NOTE]
.Review instructions
====
Verify that the configuration management plan covers all relevant configuration item types, that each configuration item card documents the required aspects (storage, access control, versioning, change history, authorization, acceptance, integrity, and backup), and that cross-references between configuration items are consistent and accurate.
====

**Note**: The reviewer cannot be the same person as the owner or the approver of the document.
