== Introduction

This document is a review of security requirement testing in a development project.

=== Goal of testing

The goal of security requirement testing is to test that

* Security requirements have been correctly implemented
* When security requirements mitigate cyber risks, security requirement testing acts as mitigation testing. In this case, the testing should include, where practical, tests that attempt to defeat (thwart) the mitigation.
